# Release 2.3.1

The release starts from committed terminal-capacity fix `69175204`. The shared working tree's unrelated deletions and uncommitted deployment record are excluded. App, lockfile and companion versions are synchronized at 2.3.1; bridge protocol remains 16. The release title follows the existing convention: `2.3.1 Web GPT Agent fork`.

The first preflight refused the previous tunnel-client v0.0.19 pin because the official latest release is v0.0.20. All six official v0.0.20 platform archives were downloaded and measured. Each archive's SHA-256 agrees with its packaging pin, the official SHA256SUMS file and the GitHub release asset digest. The release notes describe automatic live-slot retirement, bounded retention of 256 completed results, explicit output collection, preserved chat ownership and the tunnel-client update. No browser-connection fix is claimed.
