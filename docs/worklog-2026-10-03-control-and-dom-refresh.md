# Control-client exhaustion and companion refresh

Date: 2026-10-03. Source fixes only; no package, installation, production restart or private-ledger edits.

## Root failures and changes

- `src/main/work/control-socket.ts`: overflow clients received a refusal through an untracked bare `end()`. An unread peer hello could retain the server-side descriptor and prevent `server.close()` from completing. Refusals now have error/close handlers before writing, flush then destroy, and remain shutdown-owned until closed. The sixteen-client admission limit and authentication are unchanged.
- `src/main/daemon-client.ts`: each GUI invocation opened a control connection without admission control. The shared owner now permits eight concurrent invocations and sixty-four FIFO waiters, leaving room for the push subscription and lifecycle/CLI requests. Waiters retain their renderer UUID and payload; retiring that view rejects them before dispatch. Independent operations still use independent connections. No mutation retries or arbitrary GUI deadlines.
- `src/renderer/chat.ts`: every state push launched another session-control read. One in-flight read plus one latest dirty refresh now coalesces pushes. Synchronous selection retirement and A→B→A generation fences remain.
- `extension/content.js`: accepted question openings and exact turn adoption now expedite the existing activity pull instead of inheriting its ten-/thirty-second idle deadline. Companion-only mutations are filtered before terminal admission; real native Stop transitions remain urgent. Settled captures coalesce under the exact owner. Repeated legacy-label cleanup and the dead paint wrapper are removed from hot ticks; takeover/preferences still restore marked labels.
- `extension/fiber.js`: previous/current stamped-node cleanup replaces four descendant queries per historical section. Shell unit enumeration happens once; tool description processing stops at its existing bound. The linear geometry pass remains to preserve exact viewport selection for collapsed/transformed layouts. MAIN/isolated protocol version remains 18.

## Navigation-epoch capture correction

- The preceding drain kept its queue marker across a pending capture but fenced only execution, not queue admission. An A→B→A navigation could therefore let the retired epoch block the new settled turn's final revision. `watchTranscript` now owns one identity marker containing the navigation epoch and terminal/settled kind. New epochs admit their own capture immediately; terminal work still preempts settled work, and callbacks/cleanup can release only their exact marker. No new observer, timer, retry, protocol or persistence was added.
- The new deterministic regression failed before the source fix: only `C initial` was emitted, not the later final revisions. After the fix, all fifteen scheduling tests passed, including existing same-epoch coalescing and native terminal preemption. The new test exercises production route retirement/reset, finish and Fiber ownership/capture code with a real jsdom MutationObserver, controlled responses and fake timers. It also rejects the old snapshot and retains the successor's latest dirty revision while its capture is held.
- Independent isolated Electron/Chromium smoke exercised production navigation/reset/finish and Fiber capture with native MutationObserver/microtasks. An old capture timed out into a held repair; after A→B→A, the new turn emitted `C initial`, `C complete` and `C complete latest` while the old repair resolved. Five page-model requests were observed and the old snapshot did not enter the new turn. The fixture explicitly supplied hidden visibility, manually drove the existing timeout and controlled app/helper responses; it does not prove browser freezing or signed-in provider behavior. Initial smoke fixture failures were a duplicate production constant and selecting an already-completed request's timeout; only the fixture was corrected.

- `npm run verify` passed the ripgrep, privacy and license/native-source checks, then stopped at a new test-only jsdom `DOMWindow`/`MessageEventSource` typing mismatch. The fixture now constructs the reply event and defines its exact window source without a cast; typecheck passed. The remaining pipeline was resumed without repeating its successful stages: Electron resolution passed, 5,945 main-suite tests passed with 84 skipped, and all six isolated MCP shutdown tests passed (5,951 total).
- The temporary Chromium smoke script and its isolated runtime directory were removed. This correction changes raw extension source, its regression and existing documentation only; no build, package, installation, production restart or live-ledger edits were performed.

Signed-in ChatGPT acceptance was unavailable: native automation remained behind macOS permission gates and the existing Chrome CDP endpoint timed out at the WebSocket handshake. The installed app/extension remain unchanged; these checks do not establish a live hotfix.
