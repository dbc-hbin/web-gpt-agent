## 2.3.0 Web GPT Agent fork

### Workspace and editing

- Add a read-only Git Review panel with local branch comparisons, recorded edit diffs, and base/ours/theirs views for merge conflicts.
- Add optional code checkpoints before a turn's first patch, with comparison and confirmed restore. Checkpoints start disabled; restore preserves a before-restore checkpoint and refuses changed targets.
- Edit and resubmit an earlier question from the app, retain its replacement history, and show the files changed by each answer. Failed delivery preserves newer composer drafts.

### Reliable long-running work

- Preserve exact native composer text when ChatGPT's Markdown serializer would otherwise escape a framed opening. The companion uses the exact editor's temporary plain-text mode, restores its original mode after the draft retires, and keeps strict Send receipts and completed-turn ownership. Restored Compact & Resume drafts are prepared before Send is armed.
- Start fresh turns during long non-Pro work, with a configurable interval and a guarded Stop-and-continue fallback. Running calls and their responses drain before an automatic Stop, and a person's Stop cancels the automatic continuation.
- Add an optional Goal step reviewer for recorded edits. It starts disabled, never reviews Loop, and blocking review findings pause Goal.
- Retain workers that start late, back off when ChatGPT repeatedly limits history, and spend no recovery reload on input that cannot currently be offered. Untaken automatic Continue messages can become ordinary messages only while their original question remains current.
- Refuse app sends into a confirmed signed-out ChatGPT, handle announcement dialogs covering an idle composer, and recover eligible tabs from Chrome's offline error page.

### Privacy, performance and diagnostics

- Enable recognizable-credential masking for model-facing tool results, progress notifications and retained code-mode recordings, with global and per-project controls. Local files and command bytes are unchanged.
- Join request IDs that differ only in the UUID version digit while preserving the first exact owner. Add bounded request-origin, startup and recovery diagnostics.
- Reduce session-read disk writes, coalesce extension journal publication, avoid idle terminal re-theming, and retain eligible PNG screenshots as lossless WebP.
- Update the bundled OpenAI tunnel client to v0.0.19 with target-specific verified checksums.

Includes upstream Chat On Steroids improvements through `2fdc777d`; original contributor credit is retained in the integration commits.

Reload the companion extension and refresh all Web GPT Agent plugins in ChatGPT after updating. Existing histories and uncertain Send receipts are preserved rather than rewritten or replayed.
