## 2.3.1 Web GPT Agent fork

- Free terminal execution slots automatically after commands exit and their output streams close. Unread completed results no longer fill the 64 live-command slots.
- Keep the latest 256 completed results, including unread output, in a bounded cache. Older output expires, and unavailable-session guidance explains that work must not be repeated solely to recover an expired result.
- Remove the four-unread-results launch refusal. Both terminal tool descriptions require reading every returned running `session_id` through completion with `write_stdin({session_id, chars:""})`.
- Preserve chat ownership, bounded output history, and omission metadata when collecting completed results. Another chat still cannot read output or write to a terminal it does not own.
- Update the bundled OpenAI tunnel client to v0.0.20 with verified checksums for Windows, macOS and Linux on x64 and arm64.

Reload the companion extension and refresh Web GPT Agent plugins in ChatGPT after updating.
