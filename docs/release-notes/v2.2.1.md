## 2.2.1 Web GPT Agent fork

- `apply_patch` now reports what it changed: the applied A/M/D list, per-path status and change counts, move and destination-replacement notices, and short numbered excerpts of the new text. Source excerpts require Read permission; with Read off the receipt keeps paths, statuses and counts.
- Upgrade the bundled native Desktop engine to CUA Driver 0.31.0. Element input follows the driver's own token and capture ownership, a screenshot-only window capture can still authorize pixel input, and the agent cursor can be inspected without granting session administration.
- Control-client exhaustion fix: an overflow control connection is refused, flushed and closed instead of holding backend shutdown open, and the desktop client bounds its parallel GUI invocations so state pushes cannot starve Stop.
- Companion fixes: the activity feed is pulled immediately when a question opens or a live turn is adopted, settled transcript captures coalesce under their exact document epoch, and a capture held across A→B→A navigation no longer blocks the new turn's final revision.
- MCP retry guidance moved into the Core, Desktop and Plugins `exec` descriptions and Core `exec_read`, so a refused request is corrected and retried from the tool that failed rather than from initialize instructions.
- Refresh the local third-party notice snapshot, and cover the Korean language button in the Setup guide verification.

Reload the companion extension and refresh all Web GPT Agent plugins in ChatGPT after updating.
